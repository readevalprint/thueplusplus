Thue++ Lisp CGI example

This directory can be served with Python's built-in CGI server: 

cd examples/lisp
make serve-cgi

The root / page is static. Python's http.server --cgi only executes files below /cgi-bin/ or /htbin/, so the Lisp CGI adapter lives in cgi-bin/lisp-example-adapter.cgi.

  • Run the Lisp CGI smoke endpoint
  • Do not open /cgi-bin/ directly; it is not a script file.

Expected response body from the smoke endpoint: 

method=GET
path=/health
query=a=1
