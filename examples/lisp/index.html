Thue++ Lisp CGI examples

This directory can be served with Python's built-in CGI server: 

cd examples/lisp
make serve-cgi

Python's http.server --cgi only executes files below /cgi-bin/ or /htbin/. The root page stays static and links to the checked examples exposed by the trusted adapter.

  • Plain text smoke example — runs cgi-example.lisp and echoes whitelisted request metadata.
  • HTML form example — runs cgi-forms-example.lisp and reflects submitted values only through escape-html.

Expected plain text response body from the smoke endpoint: 

method=GET
path=/health
query=a=1
