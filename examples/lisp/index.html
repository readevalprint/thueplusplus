Thue++ Lisp web demo

This directory can be served with Python's built-in CGI server: 

cd examples/lisp
make serve-cgi

Python's http.server --cgi only executes files below /cgi-bin/ or /htbin/. This demo uses a tiny, app-specific adapter, web-demo.cgi, beside its Lisp source, web-demo.lisp. The adapter only invokes Thue++; the Lisp app owns the explicit route table, response rendering, query/form helpers, escaping, and framework 404s.

  • Web framework demo
    • GET / — HTML index from an explicit route table.
    • GET /hello/Ada — RE2 route-param capture escaped before HTML output.
    • GET /form — URL-encoded query value reflected only through escape-html.

Intentional omissions for this raw MVP: Flask-style route sugar, decorators, globals, static files, sessions, cookies, JSON, middleware, streaming, async, and templates.
