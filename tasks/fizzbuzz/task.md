# FizzBuzz

Read one integer `n` from stdin and print the numbers from 1 through `n`, one per line.

When the number is divisible by 3 print `Fizz`. When it is divisible by 5 print `Buzz`. When it is divisible by both print `FizzBuzz`.

The Go test checks 1 and 15, plus seeds 3, 8, and 20. Every input is in `1..20`.
