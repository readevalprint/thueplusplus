# Exponentiation operator

Read a base and an exponent, one per line, and print the base raised to that exponent and a newline. `0^0` is 1.

The base is in `0..12` and the exponent is in `0..8`. The Go test checks `0^0`, `2^8`, `5^0`, and `0^5`, plus seeds 1, 6, and 9.
