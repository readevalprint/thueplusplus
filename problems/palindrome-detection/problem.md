# Palindrome detection

Read one integer `n` from stdin and print `true` or `false` and a newline. `true` means the decimal spelling of `n` reads the same forwards and backwards.

`n` is in `0..999`. The Go test checks 0, 7, 10, and 121, plus seeds 5, 13, and 21.

Adapted from the Rosetta Code task [Palindrome detection](https://rosettacode.org/wiki/Palindrome_detection). That task is available under the GNU Free Documentation License 1.3.
