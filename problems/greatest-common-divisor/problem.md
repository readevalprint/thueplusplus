# Greatest common divisor

Read two non-negative integers, one per line, and print their greatest common divisor and a newline. `gcd(0, 0)` is 0.

Each integer is in `0..100`. The Go test checks 0 and 0, 48 and 18, and 7 and 1, plus seeds 3, 11, and 21.

Adapted from the Rosetta Code task [Greatest common divisor](https://rosettacode.org/wiki/Greatest_common_divisor). That task is available under the GNU Free Documentation License 1.3.
