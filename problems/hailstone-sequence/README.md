---
title: Hailstone sequence
---

Read one integer `n` and print the hailstone sequence from `n` down to 1, one number per line. An even term is halved. An odd term becomes three times itself plus one.

`n` is in `1..20`. The Go test checks 1, 2, and 6, plus seeds 5, 11, and 19.

Adapted from the Rosetta Code task [Hailstone sequence](https://rosettacode.org/wiki/Hailstone_sequence). That task is available under the GNU Free Documentation License 1.3.
