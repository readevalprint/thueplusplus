---
title: Fibonacci sequence
---

Read one integer `n` from stdin and print `F(n)` and a newline. `F(0)` is 0 and `F(1)` is 1.

`n` is in `0..12`. The Go test checks 0, 1, 2, and 10, plus seeds 4, 7, and 12. A program that prints one constant fails the seeded case, and the failure names that seed.

Adapted from the Rosetta Code task [Fibonacci sequence](https://rosettacode.org/wiki/Fibonacci_sequence). That task is available under the GNU Free Documentation License 1.3.
