---
title: Reverse a string
---

Read one line of letters and print those letters in reverse, then a newline.

The Go test checks `stressed` and `a`, plus three seeded words of three to six letters.

Adapted from the Rosetta Code task [Reverse a string](https://rosettacode.org/wiki/Reverse_a_string). That task is available under the GNU Free Documentation License 1.3.
