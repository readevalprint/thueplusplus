---
title: Sum of an array
---

Read a count `n`, then `n` non-negative integers, one per line. Print their sum and a newline. A count of 0 prints 0. This problem is the sum half of the Rosetta task. It does not print a product.

`n` is in `0..8`.

Adapted from the Rosetta Code task [Sum and product of an array](https://rosettacode.org/wiki/Sum_and_product_of_an_array). That task is available under the GNU Free Documentation License 1.3.
