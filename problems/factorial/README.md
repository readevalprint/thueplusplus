---
title: Factorial
---

Read one non-negative integer `n` from stdin and print `n!` and a newline. `0!` is 1.

`n` is in `0..10`. The Go test checks 0, 1, and 10, plus seeds 4 and 6.

Adapted from the Rosetta Code task [Factorial](https://rosettacode.org/wiki/Factorial). That task is available under the GNU Free Documentation License 1.3.
